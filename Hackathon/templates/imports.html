How the import works

Review these rules before loading your dataset.

01
Header mapping

The importer recognizes common names such as institution, college, title, case status, bureau, and cell.

02
Validation and normalization

Rows missing institution name or subject are skipped. Unknown category or status values fall back to safe defaults.

03
Department matching

Department names or short codes must match a configured bureau/cell; unmatched values remain unassigned.

04
Import result

The result reports records added, skipped rows, and a list of the first validation issues.
